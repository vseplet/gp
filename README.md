# gp — Git Profile Manager

CLI-утилита для управления несколькими Git-профилями. Позволяет легко переключаться между рабочим и личным аккаунтами GitHub/GitLab, используя разные SSH-ключи и идентификаторы.

## Зачем это нужно?

Если у вас несколько Git-аккаунтов (личный, рабочий, для open-source), то при работе с репозиториями возникают проблемы:
- Коммиты уходят не от того имени/email
- SSH-ключи конфликтуют между аккаунтами
- Приходится вручную менять конфиг для каждого репозитория

**gp** решает эти проблемы — создаёте профили один раз, затем просто указываете нужный при клонировании или применяете к существующему репозиторию.

## Установка

Требуется [Deno](https://deno.land/).

```bash
# Клонировать репозиторий
git clone https://github.com/vseplet/gp.git
cd gp

# Установить глобально
deno task install
```

## Использование

### Создание профиля

```bash
gp profile add work
```

Утилита запросит имя и email, затем автоматически сгенерирует SSH-ключ и покажет публичный ключ для добавления в GitHub/GitLab.

### Список профилей

```bash
gp profile list
```

### Клонирование с профилем

```bash
# С указанием профиля
gp clone git@github.com:user/repo.git -p work

# Без указания — появится интерактивный выбор
gp clone git@github.com:user/repo.git
```

Репозиторий будет склонирован с использованием SSH-ключа профиля, а локальный конфиг автоматически настроен.

### Применение профиля к существующему репозиторию

```bash
cd existing-repo
gp use work
```

### Удаление профиля

```bash
gp profile remove work

# Сохранить SSH-ключ при удалении
gp profile remove work --keep-key
```

### Просмотр деталей профиля

```bash
gp profile show work
```

## Как это работает

Каждый профиль содержит:
- **name** — имя для коммитов
- **email** — email для коммитов
- **sshKey** — путь к SSH-ключу

Профили хранятся в `~/.gitprofiles.json`, SSH-ключи — в `~/.ssh/gitprofile_<name>`.

При применении профиля устанавливаются локальные настройки репозитория:
```bash
git config user.name "..."
git config user.email "..."
git config core.sshCommand "ssh -i ~/.ssh/gitprofile_<name> -o IdentitiesOnly=yes"
```
